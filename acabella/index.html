The ACABELLA tool

ACABELLA analyzes the security of pairing-based attribute-based encryption (ABE) schemes from their pair encodings. It checks properties that imply security proofs in the AC17, ABGW17 and RW22 frameworks, and otherwise looks for master-key and decryption attacks in the Venema–Alpár framework. The ISABELLA extension computes the substitution vectors that prove security for the broader class of schemes introduced in that paper.

Everything runs in your browser: the schemes you enter are not sent anywhere, and the page stores nothing on your device.

Describe your scheme

Enter the key encodings, ciphertext encodings and public parameters as polynomials, one per line. Use variable names, integers, + - * / and parentheses. Switch on each analysis you want to run.

For pair encoding schemes in the ISABELLA class. ACABELLA checks that the encodings have the required form and returns the substitution vectors for the security proof, or explains which condition fails.

About the tool

ACABELLA was created by Antonio de la Piedra, Marloes Venema and Greg Alpár. The ISABELLA extension was created by Doreen Riepel, Marloes Venema and Tanya Verma.

We remember Antonio, who worked on ACABELLA and the early stages of the extension but passed away before he could see the fruits of his work. He is missed tremendously.

This page runs the Python code from the ISABELLA repository with Pyodide, served from this website together with SymPy and MathJax: your browser contacts no other server and stores nothing. Source code is released under the GNU General Public License v3.
